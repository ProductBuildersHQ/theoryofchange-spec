# User Guides

These guides take you from a first impact model to reports, review, and an AI agent
working on the same file. Each one stands alone; read them in this order if you
are new.

1. [Getting started](getting-started.md): install, create an impact model, check it.
2. [Authoring an impact model](authoring.md): the model, and how to change it safely.
3. [Measuring progress](measurement.md): observations, status, and what changed.
4. [Reports and decks](reports-and-decks.md): the artifacts for each audience.
5. [Review round trip](review-round-trip.md): ask reviewers, bring answers back.
6. [Quality and judging](quality-and-judging.md): lint, rubrics, and judges.
7. [MCP server and agent skills](mcp-and-skills.md): working with an AI agent.
8. [Examples](examples.md): three fictional, complete impact models.
9. [CLI reference](cli.md): every command, flag convention, and exit code.

For the concepts behind the model, see the
[research brief](../research/theory-of-change.md); for how each concept maps to
a Go type, see [Concepts to Go types](../concepts.md).
