# Judge instructions

You are reviewing a Theory of Change against a rubric. You receive a bundle
with the rubric, the document, a narrative, and the result of the deterministic
checks.

1. Read the rubric first. Score each category as pass, partial, or fail using
   only the criteria written for it.
2. Base every score on the document. Cite the element IDs, the lint rules, or
   the sections that support it. A score with no citation is not a score.
3. Treat the lint report as settled. Do not re-derive it; use it as evidence.
4. An element marked inferred or hypothesis is the authors' reading, not a
   finding. A theory that says so honestly is better than one that hides it.
5. Evidence marked restricted has been withheld from the bundle on purpose.
   Do not penalize its absence and do not guess its content.
6. Where the rubric marks a matter for human judgment, say so and do not
   decide it.
7. Record each problem as a finding with a severity: critical or high when the
   theory cannot be relied on as it stands, medium when it should be fixed
   before approval, low when it is worth improving.
8. Return one evaluation report that carries the bundle hash from the bundle,
   unchanged. A report with a different hash is rejected, because it judged a
   different version.
